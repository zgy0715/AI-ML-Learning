# 第9课：线性回归 — 预测连续值

## 什么是回归问题？

**回归（Regression）** 是机器学习中用来**预测一个连续数值**的任务。

生活中的回归问题：
- 房价预测：80平米的房子值多少钱？
- 天气预报：明天最高温度是多少度？
- 股票预测：明天收盘价是多少？
- 销量预测：下个月能卖多少件？

对比一下：

| 问题类型 | 输出 | 例子 |
|:--------:|:----:|:----:|
| **回归** | 连续数字（如 65.3万） | 房价、温度、销量 |
| **分类** | 离散类别（如 "猫"/"狗"） | 垃圾邮件、图片识别 |

## 线性回归的核心公式

```
y = wx + b
```

| 符号 | 名称 | 含义 | 例子（房价） |
|:----:|:----:|:----|:------------:|
| **x** | 特征/输入 | 已知数据 | 房子面积（80平米） |
| **y** | 标签/输出 | 要预测的值 | 房价（65万元） |
| **w** | 权重/斜率 | x 每增加1，y 增加多少 | 每多1平米涨0.5万 |
| **b** | 偏置/截距 | x=0时的基础值 | 最小成本15万 |

### 直观理解

```
价格(万)
  ^
 90|                    * 
 80|                *
 70|            *        y = 0.5x + 15
 60|        *      (这条线就是模型)
 50|    *
 40|* 
 30|
  +-------------------------> 面积(平米)
     30  50  80  100  120  150
```

线性回归的目标：**找到一条直线，让它尽可能"贴合"所有的数据点。**

---

## 损失函数：如何衡量直线贴不贴合？

**均方误差（Mean Squared Error, MSE）**

```
MSE = 1/n × Σ(预测值 - 真实值)²
```

例子：
```
真实房价：  40万  55万  65万  75万  90万
预测房价：  38万  52万  68万  72万  88万
误差：      2万   3万   -3万  3万   2万
误差平方：  4     9     9     9     4
MSE = (4+9+9+9+4) / 5 = 7.0
```

**为什么误差要平方？**
1. 正负误差不会互相抵消（2 + (-3) ≠ -1）
2. 放大大的误差（让模型更在意大错误）

**MSE 越小 → 直线拟合越好 → 模型越准确**

## 梯度下降：模型如何学习？

### 直觉比喻：下山

想象你蒙着眼站在山顶上，要走到山谷最低点：

1. **用脚探哪个方向最陡** → 计算梯度
2. **朝最陡的方向迈一步** → 更新参数
3. **重复以上两步** → 直到到达谷底

### 数学原理

梯度就是损失函数的**偏导数**，它告诉我们：
- 往哪个方向调整 w，损失会变小
- 往哪个方向调整 b，损失会变小

```
w = w - 学习率 × ∂loss/∂w
b = b - 学习率 × ∂loss/∂b
```

### 学习率（Learning Rate）

**学习率决定了每一步迈多大：**

```
学习率太大：
  一步跨太大，直接跳过山谷
  → 损失爆炸（发散）

学习率太小：
  步子太小，走半天还在山上
  → 训练太慢

学习率适中：
  每一步稳稳地朝谷底走
  → 最终到达最低点
```

## 特征归一化（Feature Scaling）

### 为什么需要归一化？

假设房价预测有两个特征：
- 面积：30~150（很大的数字）
- 卧室数量：1~5（很小的数字）

如果不归一化，面积的特征值大 → w 的梯度巨大 → 训练不稳定。

### 怎么做归一化？

**Z-score 标准化：**

```
x_norm = (x - μ) / σ
```

其中 μ 是均值，σ 是标准差。

归一化后的数据：
- 均值为 0
- 标准差为 1
- 范围大约在 -3 ~ 3 之间

## 线性回归的完整流程

```
                    ┌─────────────┐
                    │  准备数据    │
                    │  (x, y)对   │
                    └──────┬──────┘
                           ↓
                    ┌─────────────┐
                    │  特征归一化  │
                    │  z-score    │
                    └──────┬──────┘
                           ↓
                    ┌─────────────┐
                    │  初始化 w,b  │
                    │  w=0, b=0   │
                    └──────┬──────┘
                           ↓
              ┌─────────────┐    ┌────────────────┐
              │  前向传播    │───→│  y_pred = wx+b │
              └──────┬──────┘    └────────────────┘
                     ↓
              ┌─────────────┐    ┌────────────────┐
              │  计算损失    │───→│  MSE(y_pred,y) │
              └──────┬──────┘    └────────────────┘
                     ↓
              ┌─────────────┐    ┌────────────────┐
              │  梯度下降    │───→│  更新 w 和 b   │
              └──────┬──────┘    └────────────────┘
                     ↓
              ┌─────────────┐
              │  收敛了吗？  │──→ 否 → 回到前向传播
              └──────┬──────┘
                     ↓ 是
              ┌─────────────┐
              │  模型训练完成 │
              │  用 w,b 预测 │
              └─────────────┘
```

## 线性回归的优缺点

### 优点
- 简单直观，容易理解
- 计算速度快
- 可解释性强（w 就是"每增加1单位x，y变化多少"）
- 是许多更复杂模型的基础

### 缺点
- 只能学习线性关系（直线）
- 对异常值非常敏感
- 需要特征之间相互独立
- 现实世界很多关系是非线性的
