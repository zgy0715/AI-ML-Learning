# 第8课：什么是机器学习？

## 一、传统编程 vs 机器学习

### 传统编程是怎么工作的？

你写一个判断垃圾邮件的程序：

```python
if 包含"免费" and 包含"点击链接":
    是垃圾邮件
else:
    不是垃圾邮件
```

- 你需要自己制定规则（if 条件）
- 规则写死了，遇到新套路就不灵了
- 比如垃圾邮件改成"免~费~"你就识别不出来了

### 机器学习是怎么工作的？

你给电脑 10000 封邮件，每封标注了"垃圾"或"正常"：

电脑自己学习规律：
- "含有'免费'且来自陌生人的邮件，87%是垃圾"
- "含有'退订'链接的，90%是正常邮件"
- "纯图片没有文字的，95%是广告"

电脑自己从数据中找出规则，遇到新邮件，它能根据学到的经验来判断。

### 核心区别一句话

```
传统编程：数据 + 规则 → 答案
机器学习：数据 + 答案 → 规则
```

传统编程是你**告诉电脑规则**，机器学习是电脑**自己从数据中发现规则**。

## 二、一个生活例子：教小孩认识猫

```
传统编程方式：
  定义猫的规则：
  - 有胡须
  - 四条腿
  - 会喵喵叫
  → 结果：小孩看到老虎也叫"猫"（规则太死板）
  → 看到无毛猫说"这不是猫"（规则太严格）

机器学习方式：
  带小孩看 100 张猫的图片（各种颜色、大小、姿势）
  → 小孩自己总结："猫大概这么大小，眼睛会发亮，有尖耳朵…"
  → 再看到一只从没见过的猫，也能认出来
```

**关键区别**：传统编程需要你把所有规则写全，机器学习只需要你给足够多的例子。

## 三、机器学习的三种类型

### ① 监督学习（Supervised Learning）

有标准答案，电脑对着答案学。就像学生做题，做完对答案改错。

| 场景 | 输入（特征） | 输出（标签） | 类型 |
|------|------------|------------|:----:|
| 房价预测 | 面积、卧室数、地段 | 价格（数字） | 回归 |
| 手写数字识别 | 像素点阵（28x28） | 数字 0-9 | 分类 |
| 垃圾邮件识别 | 邮件内容 | 垃圾/正常 | 分类 |
| 图片分类 | 图片像素 | 猫/狗/鸟 | 分类 |

**回归 vs 分类**：预测数字叫回归（如房价），预测类别叫分类（如猫或狗）。

### ② 无监督学习（Unsupervised Learning）

没有答案，电脑自己找规律。就像没人告诉你这些水果叫什么，你自己根据颜色、形状把它们分成几堆。

- 电商把客户分成几类（高消费/低消费/潜力客户）
- 新闻自动归类（体育新闻放一起、科技新闻放一起）
- 搜索引擎结果聚类

### ③ 强化学习（Reinforcement Learning）

做对了奖励，做错了惩罚——像训练宠物。没有标准答案，只有"做得好不好"的反馈。

- AlphaGo 下围棋（赢了=奖励，输了=惩罚）
- 自动驾驶（安全驾驶=奖励，撞车=惩罚）
- 游戏 AI 打星际争霸

### 三种类型对比

| 类型 | 数据要求 | 应用场景 | 难度 |
|:----:|:--------:|:--------:|:----:|
| 监督学习 | 需要标注数据 | 分类、回归 | 中等 |
| 无监督学习 | 不需要标注 | 聚类、降维 | 较难 |
| 强化学习 | 需要环境交互 | 游戏、控制 | 最难 |

## 四、核心关键词

```
  ┌──────────┐     ┌──────────┐     ┌──────────┐
  │   特征    │     │   模型    │     │   预测    │
  │ (Feature) │ ──→ │  (Model)  │ ──→ │ (Predict)│
  │  输入数据  │     │ 学习的规律 │     │  输出结果 │
  └──────────┘     └──────────┘     └──────────┘
```

| 术语 | 英文 | 比喻 | 意思 |
|:----:|:----:|:----:|:----|
| **特征** | Feature | 考试题目 | 输入数据，比如"房间面积""卧室数量" |
| **标签** | Label | 标准答案 | 正确答案，比如"房价" |
| **模型** | Model | 大脑 | 学到的那套规律 |
| **训练** | Train | 做练习题 | 用数据教模型的过程 |
| **预测** | Predict | 参加考试 | 用模型对新数据做判断 |
| **样本** | Sample | 一道题 | 一条数据 |
| **数据集** | Dataset | 练习题集 | 所有数据的集合 |

## 五、机器学习的完整流程

```
      ┌──────────┐
      │ 收集数据  │  ← 数据是一切的基础，没有数据就没有 ML
      └────┬─────┘
           ↓
      ┌──────────┐
      │ 数据清洗  │  ← 去掉错误数据、补全缺失值、统一格式
      └────┬─────┘
           ↓
      ┌──────────┐
      │ 特征工程  │  ← 把原始数据变成模型能理解的格式
      └────┬─────┘
           ↓
      ┌──────────┐
      │ 选择模型  │  ← 不同问题选不同算法
      └────┬─────┘
           ↓
      ┌──────────┐
      │ 训练模型  │  ← 让模型在数据上学习（最耗时的步骤）
      └────┬─────┘
           ↓
      ┌──────────┐
      │ 评估模型  │  ← 用没见过的数据测试模型效果
      └────┬─────┘
           ↓
      ┌──────────┐
      │ 调参优化  │  ← 调整参数，让模型更好
      └────┬─────┘
           ↓
      ┌──────────┐
      │ 部署使用  │  ← 放到真实环境里用
      └──────────┘
```

## 六、常见误区澄清

| 误区 | 真相 |
|:----|:----|
| "机器学习很神秘" | 本质就是找规律，跟人学习没区别 |
| "ML 模型什么都能做" | 模型只能在它学的领域内工作 |
| "数据越多越好" | 数据质量比数量更重要 |
| "ML 不需要编程" | 需要大量编程来处理数据和调模型 |
| "训练一次就完事" | 需要持续维护和更新模型 |
