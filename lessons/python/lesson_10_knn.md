# 第10课：K近邻（KNN）— 分类算法

## 核心思想：近朱者赤，近墨者黑

KNN（K-Nearest Neighbors，K近邻）是机器学习中最直观的分类算法。

**一句话**：要判断一个新数据属于哪一类，就看它最近的 K 个邻居是哪一类，然后投票决定。

---

## 生活中的 KNN

### 例子：判断一个人的运动爱好

```
你想知道一个新同学喜欢什么运动：

你找到和他最像的 5 个朋友：
  朋友1（身高175cm，体重70kg）→ 篮球
  朋友2（身高170cm，体重65kg）→ 篮球
  朋友3（身高172cm，体重68kg）→ 篮球
  朋友4（身高168cm，体重60kg）→ 游泳
  朋友5（身高165cm，体重58kg）→ 游泳

新同学（身高173cm，体重67kg）：
  最近的 5 个邻居中 3 个打篮球 → 预测：篮球 🏀
```

### 另一个例子：判断水果

```
特征：颜色、形状、大小

一个新的水果：
  （红色、圆形、直径8cm）
  最近邻：苹果×3、桃子×1、橙子×1
  → 预测：苹果
```

## KNN 的三个核心问题

### 问题1：K 选多大？

**K 太小（如 K=1）→ 过拟合**
- 只看最近一个邻居
- 如果那个邻居是个异常点（噪声），就分错了
- 好比只凭一个朋友就定义你的为人

**K 适中（K=5 或 K=7）→ 效果最好**
- 综合多数邻居的意见
- 抗噪声能力强
- 常用选择

**K 太大（K=全体样本）→ 欠拟合**
- 只看整体的多数类别
- 忽略了局部信息
- 好比问全校人"你像谁"，不管你的朋友圈

### 问题2：怎么算"近"？

**欧氏距离（Euclidean Distance）** — 两点之间的直线距离

```
2D空间：
d = √[(x₁-x₂)² + (y₁-y₂)²]

3D空间：
d = √[(x₁-x₂)² + (y₁-y₂)² + (z₁-z₂)²]
```

就是初中学的**两点间距离公式**。

### 问题3：分类还是回归？

| 任务 | 方法 | 例子 |
|:----:|:----:|:------|
| **分类** | 少数服从多数（投票） | 判断猫还是狗 |
| **回归** | 取 K 个邻居的平均值 | 预测房价 |

## KNN 决策边界

**决策边界**就是模型把不同类别分开的"分界线"。

```
                ● ● ● ● ●
                ● ● ● ● ●
    ○ ○ ○ ○    ● ● ● ● ●
    ○ ○ ○ ○    ● ● ● ● ●
    ○ ○ ○ ○   ──╲──────
    ○ ○ ○ ○     ╲     ● ● ● ●
                ▲  ╲ ● ● ● ● ●
    新点在这里→ ★    ● ● ● ● ●
                ──────╱
                红色区域  │  蓝色区域
                （分到A类）│  （分到B类）
```

**不同 K 值的决策边界不同：**
- K=1：边界非常曲折，紧贴每个点（过拟合）
- K=5：边界平滑许多（泛化好）
- K=全体：整片区域都是一种颜色（欠拟合）

## KNN 的完整流程

```
                    ┌─────────────┐
                    │  存储所有    │
                    │  训练数据    │
                    └──────┬──────┘
                           ↓
              ┌─────────────────────┐
              │  收到一个新样本 x    │
              └──────┬──────┘
                     ↓
              ┌─────────────────────┐
              │  计算 x 到所有训练   │
              │  点的欧氏距离       │
              └──────┬──────┘
                     ↓
              ┌─────────────────────┐
              │  按距离从小到大排序  │
              └──────┬──────┘
                     ↓
              ┌─────────────────────┐
              │  取前 K 个最近的点   │
              └──────┬──────┘
                     ↓
              ┌─────────────────────┐
              │  统计 K 个邻居的     │
              │  类别，投票决定      │
              └──────┬──────┘
                     ↓
              ┌─────────────────────┐
              │  返回预测结果        │
              └─────────────────────┘
```

## 懒惰学习（Lazy Learning）

KNN 是一种**懒惰学习**算法：

| | 传统算法（如线性回归） | KNN |
|:--|:---------------------|:---:|
| **训练时间** | 需要训练（算梯度） | **不需要训练**（直接存数据） |
| **预测时间** | 快（只需算 wx+b） | 慢（要算所有点的距离） |
| **内存需求** | 小（只存 w 和 b） | 大（要存所有训练数据） |

**KNN 的训练时间为 0**——它只是把数据存起来，等到预测的时候才干活。

---

## KNN 的优缺点

### 优点 ✅
- 简单直观，容易理解
- 不需要训练，实现简单
- 对异常数据不太敏感
- 天然支持多分类（不止两类）
- 新增数据不需要重新训练

### 缺点 ❌
- 预测慢（大数据集上不可用）
- 需要大量内存存所有数据
- 对特征尺度敏感——**必须做归一化**
- **维度灾难**：特征越多，效果越差（高维空间距离失去意义）
- 不擅长高维数据

---

## 什么时候用 KNN？

**适合**：
- 小数据集（几千条以内）
- 低维数据（几个特征）
- 分类边界不规则
- 需要快速原型验证

**不适合**：
- 大数据集（预测太慢）
- 高维数据（文本、图像）
- 需要快速预测的场景

## 关键术语速查

| 术语 | 英文 | 含义 |
|:----:|:----:|:------|
| K近邻 | K-Nearest Neighbors | 找最近的K个点投票 |
| 欧氏距离 | Euclidean Distance | 两点间的直线距离 |
| 决策边界 | Decision Boundary | 不同类别的分界线 |
| 过拟合 | Overfitting | K太小，太在意局部噪声 |
| 欠拟合 | Underfitting | K太大，忽视局部信息 |
| 懒惰学习 | Lazy Learning | 不训练，预测时才计算 |
| 维度灾难 | Curse of Dimensionality | 特征太多时距离失效 |
