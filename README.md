# 🚀 AI机器学习学习计划

## 学习路线图

```
Phase 1: Python基础 ────────────────────── 第1-4课
  ├── 第1课：第一个程序、变量、数据类型
  ├── 第2课：条件判断、循环
  ├── 第3课：列表、字典、函数
  └── 第4课：模块、文件操作、异常处理

Phase 2: Python数据科学生态 ──────────────── 第5-7课
  ├── 第5课：NumPy数值计算
  ├── 第6课：Pandas数据分析
  └── 第7课：Matplotlib数据可视化

Phase 3: 机器学习入门 ──────────────────── 第8-11课
  ├── 第8课：机器学习是什么
  ├── 第9课：线性回归（预测）
  ├── 第10课：KNN分类（分类）
  └── 第11课：模型评估

Phase 4: 深度学习基础 ──────────────────── 第12-14课
  ├── 第12课：神经网络概念
  ├── 第13课：PyTorch入门
  └── 第14课：图像分类实战

Phase 5: 项目实战 ──────────────────────── 第15课+
  └── 自主完成AI项目
```

## 学习方法
- ✅ 每课先讲概念，再写代码
- ✅ 每课结束有**小测试**
- ✅ 代码要**自己动手敲**
- ✅ 遇到问题先思考，再问
